Назначение системы контроля версий
==================================

GitHub – крупнейший веб-сервис для хостинга IT-проектов и их совместной
разработки. Веб-сервис основан на системе контроля версий Git.
Ознакомиться с документацией по работе с GitHub можно на сайте GitHub Help.

Система контроля версий (СКВ) позволяет:
- сохранять историю изменений файлов проекта;
- возвращаться к предыдущим версиям;
- вести параллельную разработку в отдельных ветвях;
- объединять изменения и разрешать конфликты.
